# BlackLine 設計支援 Agent の構想

このプロジェクトでは、完成済みの Markdown 要件定義書から BlackLine（BL）の設計を進めるために、「どういうプロセスで進めるか」「どんな情報が必要か」「その情報をどう用意するか」を検討する。

BL での入金消込と ERP への反映、ERP データを用いた勘定照合などを題材とする。ここで得た構想をもとに、別プロジェクトで次の Agent を作る。

- 情報収集 Agent：設計に必要な情報と不足を特定し、根拠付きの情報を収集・整理する。
- 設計 Agent：収集された情報から設計案を作り、判断事項や追加調査を提示する。

本プロジェクトの成果物は、プロセス案、情報体系、収集方法のアイデア、Agent 間の受け渡し仕様、評価方法などの構想資料。実案件の設計書作成や Agent の実装は別プロジェクトで行う。

- [設計に必要な情報の候補](docs/design-input-guide.md)：情報体系を考えるための参考一覧。

## 進め方

一つの仮想業務で、要件から設計判断までに必要な情報と入手方法を机上でたどる。その結果から情報収集と設計の役割・受け渡しを具体化し、別シナリオでも成立するか確認する。実際の要件定義書の持ち込みは必須としない。

将来は設計から試験項目を作り、Playwright によるブラウザ試験へつなげることも視野に入れるが、当面の検討範囲は設計までとする。
